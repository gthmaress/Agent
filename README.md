# DeepAgent

> AI-agent built with [DeepAgents](https://github.com/langchain-ai/deepagents) and Python.

## Requirements

- Python 3.14.6
- Poetry

## Installation

### 1. Clone the repository
```bash
git clone <repository>
cd DeepAgent
```

## 2. Install dependencies
```bash
poetry install
```

## 3. Configure environment variables
Create a .env file based on the provided example:
```bash
cp .env.example .env
```

## 4. Run
```bash
poetry run python main/run.py
```
